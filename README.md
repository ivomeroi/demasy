# demasy
Plataforma web para kinesiólogia que captura y visualiza señales EMG bilaterales en tiempo real durante ciclismo en bicicleta fija. Detecta desequilibrios de potencia y asimetrías del pedaleo entre piernas. Incluye gestión de pacientes, asistente IA y almacenamiento offline. Proyecto de tesis de ingeniería Biomédica en la UNC.
